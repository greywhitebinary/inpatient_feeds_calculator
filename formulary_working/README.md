# Working formulary data

`canada_formulas_working.csv` is the maintained product dataset used by this
calculator. It is a starting library for an RD-managed `My Formulary`; it is
not an approved institutional formulary.

The clinician-facing library has one hospital-use profile per formula. Source
format, container volume, document, and verification date remain maintenance
metadata rather than choices made during routine formula selection. Values
should be checked against the current local product label and institutional
formulary before clinical use.

`modular_products_working.csv` is maintained separately because modulars use a
dose or serving basis rather than the per-millilitre basis used by formulas.
Manufacturer documents supporting the maintained values are stored in
`formula_sources/`.
